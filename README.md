# k-memory-repository
**股票数据中心**是一款记录和展示 A 股行情的本地小工具：后台从行情平台取回每日开收、成交量等数据入库，前端用深色科技风界面直观呈现 K 线图。  后台最省心的是 "开箱即用"：无需繁琐配置，表结构自动建好，开发者只管业务。采集按交易日智能比对，重复数据自动跳过；免费接口调用次数有限，系统先存一份清单备用，次数用完自动改用旧数据，搜索与采集互不干扰。  前台的妙处是 "数据一变、界面即动"：后台返回新数据，K 线图立刻刷新，无需手动操作；图表用完自动释放资源，窗口缩放自适应，久用不卡。代码改动立即生效，开发体验顺滑。  前后端各司其职，把 "查行情、存数据、看图" 做得干净利落。
